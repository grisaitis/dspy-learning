# dspy-learning

A learning environment for experimenting with DSPy optimization techniques on various simple tasks and datasets.

## Overview

This project provides a clean, modular foundation for:
- Learning how to optimize prompts with DSPy
- Experimenting with different DSPy modules, optimizers, and datasets
- Comparing optimization strategies systematically
- Tracking experiments with MLflow

## Setup

### Git Hooks

After cloning:
```bash
./hooks/install
```
